# BRACU Faculty Reviews v0.5.7 — Neutral Mobile Visual Polish

This update replaces the greenish mobile atmosphere with a calmer premium neutral/whitish gradient.

## What changed
- Mobile dark mode now uses a silver-black / white-glow background instead of green/blue/yellow ambient color.
- Main landing card now feels more like black titanium glass: neutral, premium, less gaming-like.
- Mobile search focus now uses a subtle white focus ring instead of green.
- Mobile light mode also removes green/blue tint and uses warm white/cream depth.
- No JavaScript logic changed.
- No SQL required.
- No heavy mobile image added, so performance stays light.

## Deploy
Replace your main website files:
- `index.html`
- `styles.css`
- `script.js`
- `favicon.ico`
- `bracu-campus-bg.webp`
- `assets/profile-avatars/`

Admin files are included only as the current stable copy, but this update does not require an admin change.
